# 🔬 Quiz di Scienze

Collezione di **quiz interattivi** per ripassare Scienze: atmosfera, chimica, la materia, la Terra e la Luna.
Ogni quiz è un file HTML autonomo (HTML + CSS + JavaScript puro, senza dipendenze): basta aprirlo in un browser, nessuna installazione.

🌐 **Versione online:** <https://fakezeta.github.io/scienze>

## 🚀 Come usarli

### Opzione 1 — direttamente in locale
Fai doppio clic su un file `.html` (o su `index.html` per la pagina di partenza) e apri il quiz nel browser.

### Opzione 2 — GitHub Pages (già configurato)
1. I file di questo progetto sono pubblicati nel repository [`fakezeta/scienze`](https://github.com/fakezeta/scienze).
2. Il sito è attivo a **<https://fakezeta.github.io/scienze>**.
